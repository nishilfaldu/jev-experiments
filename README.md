# Jev experiments

A collection of experiments built with Jev models.

## Experiments

- [`bug-triage-demo/`](bug-triage-demo/): A visual ticket triage demo that asks Jev to analyze incoming support issues and recommend an action.
- [`pr-review-dashboard/`](pr-review-dashboard/): A GitHub pull request review dashboard that evaluates pull request changes against user-defined rules.

Each folder is a separate application with its own dependencies and setup instructions. See its README for details. Configure credentials locally; environment files are intentionally excluded from this repository.
